# Instruções de desenvolvimento

## Referência e decisões do projeto

- Consulte o `plano.md` antes de iniciar qualquer trabalho. Ele é a referência principal para os objetivos, o escopo, as prioridades e as decisões do projeto.
- Respeite as decisões aprovadas. Se uma solicitação parecer conflitante com elas, sinalize o conflito e peça aprovação antes de seguir.
- Não adicione funcionalidades, dependências ou tecnologias sem justificativa relacionada ao projeto e aprovação do responsável.
- Não altere o `plano.md` sem autorização explícita do responsável.
- Implemente uma funcionalidade por vez, mantendo o trabalho alinhado ao escopo acordado.

## Forma de trabalhar

- O objetivo é construir um produto funcional com assistência de IA. Implemente o trabalho solicitado; não transforme cada tarefa em uma aula de programação.
- Priorize soluções funcionais, seguras, organizadas e simples, adequadas às necessidades atuais do projeto.
- Antes de implementar, examine a estrutura e o código existentes para entender os padrões do projeto e evitar duplicações.
- Não crie código, arquivos, abstrações ou funcionalidades desnecessários. Faça alterações precisas e limitadas ao escopo solicitado.
- Proteja credenciais, chaves de API e dados dos usuários. Não exponha segredos no código ou em arquivos versionados.
- Nunca execute automaticamente código de projetos importados. Trate arquivos importados como não confiáveis e exija controles apropriados antes de qualquer execução.
- Não declare uma funcionalidade concluída sem executar testes pertinentes. Se não for possível testar, informe isso claramente e não a apresente como validada.

## Relato ao concluir uma tarefa

Apresente de forma objetiva:

- **Arquivos criados**
- **Arquivos modificados**
- **Resumo das alterações**
- **Como testar**, incluindo os testes executados e seus resultados
- **Limitações ou problemas encontrados**
